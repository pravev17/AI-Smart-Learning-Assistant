PYTHON – BEGINNER LEVEL
=======================

1. INTRODUCTION TO PYTHON

Python is a high-level, interpreted, general-purpose programming language.
It was created by Guido van Rossum and first released in 1991.

Python is popular because its syntax is simple, readable, and beginner-friendly.

Python is commonly used for:

• Web Development
• Data Science
• Artificial Intelligence
• Machine Learning
• Automation
• Software Development
• Scripting

Example:

print("Hello World")

The print() function displays information on the screen.


2. FEATURES OF PYTHON

Important features of Python are:

• Easy to learn and understand
• Simple and readable syntax
• Free and open source
• Portable
• Object-oriented
• Large standard library
• Supports many third-party libraries
• Dynamically typed
• Used in many different fields


3. PYTHON SYNTAX

Python uses indentation to define blocks of code.

Example:

if age >= 18:
    print("Eligible")

The spaces before print() are important.

Unlike some programming languages, Python does not normally use braces
to define blocks.


4. COMMENTS

Comments are used to explain code.

A single-line comment starts with #.

Example:

# This is a comment
print("Hello")

Comments are ignored when the program runs.


5. VARIABLES

A variable is a name used to store a value.

Example:

name = "John"
age = 20
marks = 85.5

Here:

name stores a string.
age stores an integer.
marks stores a decimal value.

Python does not require us to declare the variable type separately.


6. DATA TYPES

A data type tells us what kind of value is stored.

Important Python data types include:

1. int
Used for whole numbers.

Example:

age = 20


2. float
Used for decimal numbers.

Example:

percentage = 85.5


3. str
Used for text.

Example:

name = "John"


4. bool
Stores True or False.

Example:

passed = True


5. list
Stores multiple values.

Example:

marks = [80, 85, 90]


6. tuple
Stores an ordered collection that cannot normally be changed.

Example:

numbers = (10, 20, 30)


7. dictionary
Stores data as key-value pairs.

Example:

student = {
    "name": "John",
    "age": 20
}


8. set
Stores unique values.

Example:

numbers = {1, 2, 3, 4}


7. INPUT AND OUTPUT

The input() function is used to get information from the user.

Example:

name = input("Enter your name: ")
print("Hello", name)

The print() function is used to display output.

Example:

print("Welcome to Python")


8. TYPE CONVERSION

Sometimes we need to convert one data type into another.

Example:

age = input("Enter your age: ")

The input() function normally returns a string.

We can convert it to an integer:

age = int(input("Enter your age: "))

Common conversion functions include:

int()
float()
str()
bool()


9. OPERATORS

Operators are symbols used to perform operations.

Arithmetic operators:

+   Addition
-   Subtraction
*   Multiplication
/   Division
%   Modulus
**  Exponent
//  Floor division

Example:

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)


10. COMPARISON OPERATORS

Comparison operators compare two values.

==    Equal to
!=    Not equal to
>     Greater than
<     Less than
>=    Greater than or equal to
<=    Less than or equal to

Example:

age = 20

print(age >= 18)

The result will be True.


11. LOGICAL OPERATORS

Logical operators are used to combine conditions.

and
or
not

Example:

age = 20

if age >= 18 and age <= 60:
    print("Eligible")


12. CONDITIONAL STATEMENTS

Conditional statements allow a program to make decisions.

The main statements are:

• if
• elif
• else

Example:

marks = 75

if marks >= 90:
    print("A Grade")
elif marks >= 60:
    print("B Grade")
else:
    print("C Grade")


13. LOOPS

Loops are used when we need to execute the same block of code repeatedly.

Python mainly provides:

• for loop
• while loop


FOR LOOP

Example:

for i in range(5):
    print(i)

This prints numbers from 0 to 4.


WHILE LOOP

Example:

i = 1

while i <= 5:
    print(i)
    i += 1


14. BREAK AND CONTINUE

break is used to stop a loop.

Example:

for i in range(10):
    if i == 5:
        break
    print(i)


continue skips the current iteration.

Example:

for i in range(5):
    if i == 2:
        continue
    print(i)


15. STRINGS

A string is a sequence of characters.

Example:

name = "Python"

Strings can be accessed using indexes.

Example:

name = "Python"

print(name[0])

The output is:

P

Some useful string operations are:

upper()
lower()
strip()
replace()
split()


Example:

text = "hello"

print(text.upper())

Output:

HELLO


16. LISTS

A list is an ordered and changeable collection.

Example:

fruits = ["Apple", "Banana", "Mango"]

Accessing an element:

print(fruits[0])

Adding an item:

fruits.append("Orange")

Removing an item:

fruits.remove("Banana")


17. TUPLES

A tuple is an ordered collection that cannot normally be modified after creation.

Example:

numbers = (10, 20, 30)

Accessing an element:

print(numbers[0])

Tuples are useful when data should remain unchanged.


18. DICTIONARIES

A dictionary stores information using key-value pairs.

Example:

student = {
    "name": "John",
    "age": 20,
    "mark": 85
}

Accessing a value:

print(student["name"])

Dictionaries are useful for representing structured information.


19. SETS

A set is an unordered collection of unique elements.

Example:

numbers = {1, 2, 3, 3, 4}

The duplicate 3 is automatically removed.

Sets are useful when duplicate values are not required.


20. FUNCTIONS

A function is a reusable block of code.

Example:

def greet():
    print("Hello")

greet()

A function can also accept parameters.

Example:

def add(a, b):
    return a + b

result = add(10, 20)

print(result)


21. RETURN STATEMENT

The return statement sends a value back from a function.

Example:

def square(number):
    return number * number

answer = square(5)

print(answer)

Output:

25


22. BASIC ERROR HANDLING

Errors can occur when a program runs.

Python provides try and except to handle many runtime errors.

Example:

try:
    number = int(input("Enter a number: "))
    print(number)
except ValueError:
    print("Please enter a valid number.")

This prevents the program from stopping suddenly because of invalid input.


23. MODULES

A module is a Python file containing reusable code.

Python provides many built-in modules.

Example:

import math

print(math.sqrt(25))

The math module provides mathematical functions.


24. BASIC FILE HANDLING

Python can create, read and write files.

Example:

file = open("data.txt", "w")
file.write("Hello Python")
file.close()

A safer method is:

with open("data.txt", "r") as file:
    content = file.read()

print(content)


25. BASIC PYTHON PROGRAM

Example:

name = input("Enter your name: ")
marks = int(input("Enter your marks: "))

if marks >= 50:
    result = "Pass"
else:
    result = "Fail"

print("Student:", name)

SUMMARY

Python is a simple and powerful programming language.

At the beginner level, the main goal is to understand the basic syntax
and learn how to write small programs using variables, data types,
operators, conditions, loops, collections and functions.

Once these concepts are comfortable, the learner can move to the
Intermediate level and start learning Object-Oriented Programming,
file handling, modules, exception handling and more advanced Python
features.
